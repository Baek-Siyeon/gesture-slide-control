# Gesture-Based Slide Control System

## Project Overview
This project controls presentation slides using hand gesture recognition.

## Motivation
The goal of this project is to create a touchless and interactive slide control system using AI-based gesture recognition.

## Methods
We used a webcam to capture hand gestures and an AI model to classify them into Next, Previous, and Background.

## Results
The system successfully recognized gestures and converted them into keyboard commands for slide control.
